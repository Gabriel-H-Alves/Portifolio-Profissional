## 🛠️ Tech Stack & Architecture

- **Engine:** Vite 8 + Vanilla JavaScript (ES Modules)
- **Animation Orchestrator:** GSAP 3 (GreenSock)
- **Visuals & Canvas:** HTML5 Canvas API (Synaptic Neural Network & Particle Dynamics)
- **Styling:** Custom CSS3 Design System with CSS variables and dynamic module theme cascading
- **Performance:** **114 KB** total production bundle, sub-second loads, 60 FPS transitions

## 🚀 Quickstart

### Prerequisites
- Node.js 18+
- npm / pnpm / yarn

### Installation & Run

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/nexus-os.git

# Navigate into directory
cd nexus-os

# Install dependencies
npm install

# Run dev server
npm run dev

# Build for production
npm run build
```
